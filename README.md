
# Vault Escape Challenge

CSC 6370 - Web Programming  
Student: Isaac Owusu

## Project Overview

Vault Escape Challenge is a PHP-based escape room game.
Players register, log in, and solve three different puzzles
to escape a virtual vault.

The game uses PHP sessions to track progress, scores,
wrong attempts, and hints.

## Technologies

- PHP
- HTML5
- CSS3

## Planned Features

- User registration and login
- Three puzzle rooms
- PHP session management
- Scoring and hint penalties
- Session-based leaderboard
- Adaptive hint and difficulty system
- Responsive layout

## Running Locally

1. Open the project folder in Terminal.
2. Start the PHP development server:

   php -S localhost:8000

3. Visit http://localhost:8000 in a browser.
